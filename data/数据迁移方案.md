# 数据存储迁移方案

## 📋 方案概述

将历史记录从 **浏览器 localStorage** 迁移到 **独立的 JSON 文件**，实现数据与代码完全隔离。

---

## 🎯 当前状态

### 数据存储位置
- **localStorage 键名**：`audioVisualTrainingData`
- **查看方式**：浏览器按 F12 → Application → Local Storage
- **数据格式**：JSON 数组，每个元素代表一次实验记录

### 问题
1. 数据存储在浏览器中，清除浏览器数据会丢失
2. 不同浏览器/设备之间无法共享数据
3. 与代码混合在一起，不利于数据管理

## 🔧 接下来需要做的事情

### 选项A：纯前端方案（使用 File System Access API）

**优点**：无需服务器，数据保存在本地
**缺点**：需要现代浏览器支持，用户需要选择目录

#### 修改步骤

1. **修改 `js/dataManager.js`**，添加文件读写功能：

```javascript
// 在 DataManager IIFE 内部添加以下函数

let fileHandle = null;

// 选择数据目录
async function selectDataDirectory() {
  try {
    fileHandle = await window.showDirectoryPicker();
    const historyFileHandle = await fileHandle.getFileHandle('experiment_history.json', { create: true });
    const file = await historyFileHandle.getFile();
    const content = await file.text();
    return JSON.parse(content || '[]');
  } catch (err) {
    console.error('选择目录失败:', err);
    return null;
  }
}

// 保存数据到文件
async function saveToFile(data) {
  if (!fileHandle) {
    UIHelper.showNotification('请先选择数据目录', 'warning');
    return false;
  }
  
  try {
    const historyFileHandle = await fileHandle.getFileHandle('experiment_history.json', { create: true });
    const writable = await historyFileHandle.createWritable();
    await writable.write(JSON.stringify(data, null, 2));
    await writable.close();
    return true;
  } catch (err) {
    console.error('保存文件失败:', err);
    return false;
  }
}

// 从文件读取数据
async function loadFromFile() {
  if (!fileHandle) {
    return null;
  }
  
  try {
    const historyFileHandle = await fileHandle.getFileHandle('experiment_history.json');
    const file = await historyFileHandle.getFile();
    const content = await file.text();
    return JSON.parse(content || '[]');
  } catch (err) {
    console.error('读取文件失败:', err);
    return [];
  }
}
```

2. **修改保存数据的函数**，同时保存到 localStorage 和文件：

```javascript
async function saveExperimentData(metadata, results) {
  const data = {
    id: generateId(),
    timestamp: new Date().toISOString(),
    // ... 其他字段 ...
  };

  // 1. 保存到 localStorage（作为缓存）
  const allData = getAllData();
  allData.push(data);
  localStorage.setItem(STORAGE_KEY, JSON.stringify(allData));
  
  // 2. 保存到文件（如果已选择目录）
  if (fileHandle) {
    await saveToFile(allData);
  }
  
  UIHelper.showNotification('数据已保存', 'success');
  return data.id;
}
```

3. **在"历史记录"页面添加"选择数据目录"按钮**

在 `history.html` 中添加：

### 选项B：服务器端方案（推荐用于生产环境）

**优点**：数据集中管理，支持多用户，支持跨设备访问
**缺点**：需要服务器部署

#### 实现步骤

1. **创建简单的后端 API**（以 Node.js 为例）：

```javascript
// server.js
const express = require('express');
const cors = require('cors');
const fs = require('fs').promises;
const path = require('path');

const app = express();
app.use(cors());
app.use(express.json());

const DATA_FILE = path.join(__dirname, 'data', 'experiment_history.json');

// 获取所有数据
app.get('/api/data', async (req, res) => {
  try {
    const data = await fs.readFile(DATA_FILE, 'utf8');
    res.json(JSON.parse(data || '[]'));
  } catch (err) {
    res.status(500).json({ error: err.message });
  }
});

// 保存数据
app.post('/api/data', async (req, res) => {
  try {
    const newData = req.body;
    const existingData = JSON.parse(await fs.readFile(DATA_FILE, 'utf8') || '[]');
    existingData.push(newData);
    await fs.writeFile(DATA_FILE, JSON.stringify(existingData, null, 2));
    res.json({ success: true, id: newData.id });
  } catch (err) {
    res.status(500).json({ error: err.message });
  }
});

// 删除数据
app.delete('/api/data/:id', async (req, res) => {
  try {
    const id = req.params.id;
    let existingData = JSON.parse(await fs.readFile(DATA_FILE, 'utf8') || '[]');
    existingData = existingData.filter(d => d.id !== id);
    await fs.writeFile(DATA_FILE, JSON.stringify(existingData, null, 2));
    res.json({ success: true });
  } catch (err) {
    res.status(500).json({ error: err.message });
  }
});

app.listen(3000, () => console.log('Server running on http://localhost:3000'));
```

2. **修改 `js/dataManager.js`**，添加 API 调用：

```javascript
const API_BASE_URL = 'http://localhost:3000/api';

// 保存数据到服务器
async function saveToServer(data) {
  try {
    const resp = await fetch(`${API_BASE_URL}/data`, {
      method: 'POST',
      headers: { 'Content-Type': 'application/json' },
      body: JSON.stringify(data)
    });
    return await resp.json();
  } catch (err) {
    console.error('保存到服务器失败:', err);
    return null;
  }
}

// 从服务器加载数据
async function loadFromServer() {
  try {
    const resp = await fetch(`${API_BASE_URL}/data`);
    return await resp.json();
  } catch (err) {
    console.error('从服务器加载失败:', err);
    return [];
  }
}
```

### 选项C：混合方案（推荐）

**优点**：兼顾速度和持久化存储
**实现**：同时保存到 localStorage（缓存）和 JSON 文件（持久化）

1. **优先从 localStorage 读取**（快速）
2. **定期同步到文件**（持久化）
3. **提供导入/导出功能**（灵活性）

## 📦 数据迁移步骤

如果已经有历史数据在 localStorage 中，需要迁移到文件：

### 1. 导出 localStorage 数据

在浏览器控制台执行：
```javascript
// 获取数据
const data = localStorage.getItem('audioVisualTrainingData');
console.log(data);

// 复制到剪贴板
copy(data);
```

### 2. 保存到文件

- 粘贴到 `data/experiment_history.json`
- 或者创建一个导入页面，上传 JSON 文件

### 3. 创建导入功能

在 `history.html` 中添加文件上传输入：
```html
<input type="file" id="importFile" accept=".json" style="display:none" onchange="importData()">
<button onclick="document.getElementById('importFile').click()" 
        class="px-4 py-2 bg-green-500 text-white rounded-lg hover:bg-green-600 text-sm">
  📥 导入数据
</button>

<script>
async function importData() {
  const file = document.getElementById('importFile').files[0];
  if (!file) return;
  
  const reader = new FileReader();
  reader.onload = function(e) {
    try {
      const importedData = JSON.parse(e.target.result);
      const existingData = DataManager.getAllData();
      const mergedData = existingData.concat(importedData);
      localStorage.setItem('audioVisualTrainingData', JSON.stringify(mergedData));
      UIHelper.showNotification(`成功导入 ${importedData.length} 条记录`, 'success');
      
      // 刷新显示
      const hc = document.getElementById('historyContent');
      if (hc) hc.innerHTML = DataManager.generateHistoryHTML();
    } catch (err) {
      UIHelper.showNotification('导入失败：文件格式错误', 'error');
    }
  };
  reader.readAsText(file);
}
</script>
```

## 📝 总结

| 方案 | 优点 | 缺点 | 适用场景 |
|------|------|------|----------|
| **A. 纯前端** | 无需服务器 | 需要现代浏览器 | 单机使用、研究实验 |
| **B. 服务器端** | 集中管理、多用户 | 需要部署服务器 | 生产环境、多实验室 |
| **C. 混合** | 兼顾速度和持久化 | 实现稍复杂 | 大多数场景 |

**推荐**：先实现**选项C（混合方案）**，同时提供导入/导出功能，让用户可以灵活选择数据存储方式。
