# 视听语音整合训练系统 v3 - 项目架构与功能说明

## 项目简介

视听语音整合训练系统 v3 是一个专业的心理物理学实验平台，旨在通过视听整合训练改善被试的语音识别能力。该系统包含四个功能模块，分别针对不同的听觉认知能力进行训练和评估。

## 技术架构

### 前端技术栈
- **框架**: 原生 JavaScript (ES6+)
- **UI**: Tailwind CSS（CDN 模式）
- **音频处理**: Web Audio API
- **视频播放**: HTML5 Video API

### 后端技术栈
- **服务器**: Node.js + Express.js
- **数据存储**: JSON 文件 + LocalStorage
- **跨域支持**: CORS
- **公网访问**: Ngrok 隧道

### 核心算法
- **自适应算法**: Staircase 阶梯法（3-up-1-down）
- **心理物理拟合**: Weibull/Logistic 曲线拟合
- **阈值计算**: 80% 正确率标准

## 功能模块

### 功能一：听觉语音在噪音中的可感知程度（抗干扰训练）

**目的**: 评估被试在噪音环境下的语音识别能力

**操控变量**:
- SNR（信噪比）：12dB 至 -12dB，步长 3dB

**输出指标**:
- 噪音阈值：达到 80% 正确率所需的 SNR

**实验设计**:
- 使用阶梯法自适应调整 SNR
- 连续答对 3 次降低 SNR（变难）
- 答错 1 次提高 SNR（变易）
- 8 次反转后停止

### 功能二：视觉口型提升噪音干扰中语音的识别（视觉整合训练）

**目的**: 评估视觉口型对语音识别的辅助作用

**操控变量**:
- SNR：12dB 至 -12dB
- 口型模糊度：0% 至 60%，步长 10%

**输出指标**:
- Visual Gain（视觉增益）= 模糊口型阈值 - 清晰口型阈值
- 反映口型信息带来的识别提升

### 功能三：视听整合时延窗口对噪音干扰中语音识别的影响（异步校准训练）

**目的**: 评估视听整合的时间窗口特性

**操控变量**:
- SNR：12dB 至 -12dB
- SOA（视听异步）：-300ms 至 +300ms，步长 100ms
  - 负值：声音提前
  - 正值：画面提前

**输出指标**:
- 整合时窗宽度
- 对异步刺激的耐受曲线

### 功能四：注意训练与目标说话人定位（注意定位能力提升训练）

**目的**: 评估注意选择和干扰抑制能力

**操控变量**:
- SNR：12dB 至 -12dB
- 注意条件：
  - Single：单个说话人
  - Dual：双说话人竞争（Cocktail Party 效应）

**输出指标**:
- 干扰抑制成本 = Dual阈值 - Single阈值
- 目标选择准确率

## 实验流程

### 1. 训练前测试 (Pre-test)
- 评估被试基线能力
- 测试所有四个功能模块
- 为后续训练提供参考

### 2. 训练阶段 (Training)
- 根据前测结果选择训练模块
- 使用自适应算法进行个性化训练
- 实时反馈，循序渐进

### 3. 训练后测试 (Post-test)
- 评估训练效果
- 与前测结果对比分析
- 计算改善幅度

## 数据管理

### 数据记录
- **试次数据**: SNR、模糊度、SOA、反应时、正确率

- **心理物理参数**: 阈值、曲线拟合参数

- **JSON 格式**: 完整数据，包含元数据和原始日志

### 数据存储

## 安装与运行

### 环境要求
- Node.js (v14+)
- Python 3（用于启动脚本）
- Ngrok（可选，用于公网访问）

### 快速启动

**方式一：使用 Python 启动脚本（推荐）**
```bash
python 启动.py
```
脚本会自动：
1. 检查 Node.js 和 Ngrok
2. 清理占用的端口
3. 安装依赖（首次运行）
4. 启动服务器和 Ngrok
5. 显示访问地址

**方式二：手动启动**
```bash
# 安装依赖
npm install

# 启动服务器
npm start

# （可选）启动 ngrok
ngrok http 3000
```

### 访问地址
- **本地访问**: http://localhost:3000
- **管理员页面**: http://localhost:3000/admin.html
- **历史记录**: http://localhost:3000/history.html
- **公网访问**: 通过 Ngrok 生成的地址

## 配置说明

主要配置文件：`config/constants.js`

| 参数类别 | 参数名 | 默认值 | 说明 |
|---------|--------|--------|------|
| SNR | SNR_DEFAULT | [12,9,6,3,0,-3,-6,-9,-12] | 信噪比档位（dB） |
| SNR | SNR_STEP | 3 | SNR 步进值 |
| 模糊度 | BLUR_DEFAULT | [0,10,20,30,40,50,60] | 口型模糊度（%） |
| SOA | SOA_DEFAULT | [-300,-200,-100,0,100,200,300] | 视听异步（ms） |
| 心理物理 | PSY_CRITERION | 0.80 | 阈值标准（80%正确率） |
| 自适应 | ADAPTIVE_UP | 1 | 答错1次升级 |
| 自适应 | ADAPTIVE_DOWN | 3 | 答对3次降级 |
| 自适应 | ADAPTIVE_MAX_REVERSALS | 8 | 最大反转次数 |

## 常见问题

### Q: 如何修改实验材料？
A: 将视频和音频文件放入 `assets/` 目录，并在 `config/constants.js` 中更新 `MATERIALS` 配置。

### Q: 数据存储在哪里？
A: 数据同时存储在浏览器 LocalStorage 和服务器 `data/` 目录下。

### Q: 如何自定义 SNR 档位？
A: 修改 `config/constants.js` 中的 `SNR_DEFAULT` 数组。

### Q: 可以离线使用吗？
A: 可以，但需要使用本地服务器访问，不能直接打开 HTML 文件（因 CORS 限制）。
