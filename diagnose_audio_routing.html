这个工具将逐步测试音频系统的每个环节，找出信号音无法播放的根本原因。

测试音频文件是否能正常播放

测试通过 Web Audio API 播放

测试 3: 信号增益测试

测试不同增益值下的播放效果

测试 4: 完整路由测试

模拟主系统的音频路由

📋 诊断日志

使用说明:

  1. 依次运行测试 1-4
  2. 测试 1 如果听不到声音 → 音频文件有问题
  3. 测试 2 如果听不到 → Web Audio 路由有问题
  4. 测试 3 调整增益值，找到能听到声音的最小值
  5. 测试 4 模拟主系统，查看完整路由
  6. 将日志截图或复制给我
